# Agentic SDLC with GitHub

> A modern, safe, and scalable approach to software delivery with AI coding agents.

![Agentic SDLC with GitHub](agentic-sdlc.png)

## Overview

AI coding agents are changing how software is built.

Implementation is becoming faster and cheaper. As a result, the main engineering bottleneck is moving away from writing code toward:

- Defining clear requirements
- Architecture and design
- Automated verification
- Security
- Code review
- Deployment safety
- Human accountability

This repository proposes an **Agentic Software Development Life Cycle (SDLC)** for organizations using GitHub and AI coding agents.

The goal is not maximum agent autonomy.

The goal is:

> **Define intent, constrain the agent, verify the result, and preserve human accountability.**
